# **App Name**: LogoForge

## Core Features:

- Icon Selection: Browse and select icons from Iconfinder's extensive library using a keyword search.
- Font Selection: Select fonts from Google Fonts.
- Canvas Manipulation: Adjust the size and position of icons and text on a canvas with drag-and-drop functionality.
- Logo Download: Download the finalized logo in various formats (PNG, JPG, SVG).
- AI-Powered Layout Suggestions: Generate several layout suggestions based on the chosen icon and name; uses an AI tool to determine whether to focus on vertical/horizontal alignments, the choice of font, and relative font sizes

## Style Guidelines:

- Background: Light gray (#F0F0F0) to provide a neutral and clean workspace.
- Primary color: Teal (#008080) as the accent color to highlight key UI elements.
- Text color: Dark gray (#333333) for readability against the light background.
- Font choice: 'Inter', a grotesque-style sans-serif, will be used for its modern and neutral appearance suitable for both headlines and body text.
- Use simple, scalable vector icons for interface elements, ensuring clarity and sharpness at any size.
- Employ a clean and intuitive layout, positioning key tools and options for easy access.
- Incorporate subtle transitions and animations when adjusting elements on the canvas.
